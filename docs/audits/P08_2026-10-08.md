**Recommended: `Event` JSON-LD.** It's a real, dated event with a physical venue, and it can earn Google's event rich result. Every field matches visible content:
- name "The Awakening: Freshers Plug In"
- `startDate` 2026-10-24T16:00+01:00
- `endDate` 2026-10-25. **The end time isn't known, so it's date-only rather than an invented time.**
- `eventAttendanceMode` Offline; `eventStatus` Scheduled
- `location`: Place "Freedom Dome", address "Ilesanmi Bus Stop, Tanke", Ilorin, Kwara, NG
- `organizer`: Organization "Citizens of Light Church"
- `isAccessibleForFree`: true; `offers` price 0 NGN with the registration URL
- `image`: og.jpg

**Not added:** `LocalBusiness` (this page isn't the church's listing), reviews, ratings and opening hours (none exist).

## MANUAL CHECKLIST (builder)

**Before sharing the link (this matters):**
1. Open https://developers.facebook.com/tools/debug/ → paste the production URL → **Scrape Again**. This primes the preview cache that WhatsApp shares with Facebook.
2. Send the link to yourself on WhatsApp and check the image, title and description.
3. If the preview is ever stale after a change: Scrape Again in the Sharing Debugger. WhatsApp can keep its own cache for a while, and adding `?v=2` to the shared URL forces a fresh preview.

**Optional: Google Search Console** (church account, with the builder added as a user):
1. https://search.google.com/search-console → Add property → **URL prefix** → `https://the-awakening-rho.vercel.app/`
2. Verify with the **HTML tag** method: send me the tag and I'll add it to `index.html`.
3. Sitemaps → submit `sitemap.xml`. URL Inspection → `/` → Request indexing.

**Optional: Bing Webmaster Tools.** Sign in at https://www.bing.com/webmasters → Import from Search Console → submit the sitemap.
